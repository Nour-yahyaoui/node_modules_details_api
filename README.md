# 📚 Node.js Library Documentation API

> A curated collection of Node.js library documentation - maintained daily with Python + AI.

## 📖 What This Is

This repository contains a growing collection of **Node.js library documentation**, each entry including:

- **Description** - What the library does in plain English
- **Usage** - Simple working code examples
- **Tags** - Categorized for easy searching
- **Category** - Framework, Utility, Database, Security, etc.

## 🔄 How It's Updated

- 🤖 **AI-Generated** - Each library entry is researched and written by AI
- 🐍 **Python Automation** - The bot reads `libraries.json` and adds entries one by one
- 📊 **One Commit Per Library** - Each addition is a separate commit for activity tracking
- 📝 **Dual Updates** - Every library is added to both `data.js` AND `README.md`
